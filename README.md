# DevLinks

Página pessoal com links e perfis de Ademir Thiago Sandrini.

Resumo

- Projeto simples em HTML/CSS que exibe avatar, links e ícones sociais.
- Tema claro/escuro alternável com um botão.

Como usar

1. Abra `index.html` no navegador.
2. Clique no botão de alternar tema para ver a versão clara/escura.

Alterar a imagem de capa

A imagem de capa usada neste README está em `assets/cover.jpg`.
Para trocar, substitua `assets/cover.jpg` pelo arquivo desejado mantendo o mesmo nome.

Avatar

- Avatar para tema escuro: `assets/avatar.png` ou `assets/avatar.jpg`
- Avatar para tema claro: `assets/avatar-light.png` ou `assets/avatar-light.jpg`

Contribuição

Pull requests são bem-vindos. Para alterações locais, edite os arquivos e abra um PR.
